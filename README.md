# den-run-ai.github.io

Personal site and blog of Denis Akhiyarov: <https://den-run-ai.github.io/>

Built with [Quarto](https://quarto.org) (1.5). Sources live at the root; `quarto render` writes the site to `docs/`, which GitHub Pages serves.

- `index.qmd` home (intro, highlights, latest posts) · `research.qmd` · `projects.qmd` · `about.qmd`
- `posts/` blog posts, one folder each
- `theme.scss` and `styles.css` the look; `assets/` avatar and favicon
- `dance/` the Dance Stage page, copied as-is
